# Portavel updates

Official application and runtime updates for Portavel by [Techport](https://techport-iq.com).

The 1.0.0 baseline is prepared. Downloadable assets will be published in Releases when release preparation is complete.

Application updates preserve installed runtimes, tools, settings, websites and databases. Runtime updates are a separate choice. Portavel verifies signed metadata and each package's size and SHA-256 before installation.

This repository contains update packages and release notes. The application source and complete offline installer are distributed separately.
