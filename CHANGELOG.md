# Portavel changelog

## 1.0.0

Initial release.

- Manage Apache with embedded PHP TS, PostgreSQL, MySQL, Composer and optional Node.js/npm and Git from one Windows desktop and tray.
- Run services at boot without signing in, with supervised processes and installation ownership checks.
- Discover Laravel websites, configure domains and HTTPS, and manage Laravel scheduling.
- Configure hardware-based Apache and database profiles with validation, backups and rollback.
- Proxy JasperServer and read-only dcm4chee/Orthanc DICOMweb with cached Laravel study authorization and streamed images.
- Manage runtime versions, configuration history, logs, command launchers and signed application/runtime updates.
- Bundle self-contained applications, runtime dependencies, Notepad++, HeidiSQL and the complete Visual C++ redistributable for offline installation.
